# Schackreview (mobil)

Privat hobbyapp för att granska schackpartier. Allt räknas i webbläsaren; inga uppgifter skickas hit.

## Tredjepartsfiler

- **Stockfish 18** (`js/stockfish-18-lite-single.*`) via [stockfish.js](https://github.com/nmrugg/stockfish.js), GPL-3.0. Licenstext: `js/STOCKFISH-COPYING.txt`. Källkod: https://github.com/official-stockfish/Stockfish
- **chess.js 1.4.0** (`js/chess.js`), BSD-2-Clause. Licenstext: `js/CHESSJS-LICENSE.txt`.
- **Pjäsbilder** (`pieces/`): "maestro" av sadsnake1, CC BY-NC-SA 4.0 (https://creativecommons.org/licenses/by-nc-sa/4.0/), från Lichess (github.com/lichess-org/lila), renderade till PNG utan andra ändringar.
- **Öppningsnamn** (`data/book.json`): byggt från lichess-org/chess-openings, CC0.
